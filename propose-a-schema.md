# Propose a Schema

The IES ecosystem grows through community-proposed schemas. If you're working on a data
model that a use case needs, propose it here — tell us who you are, which use case it
contributes to, and share the schema itself.

Submitting opens a short form on GitHub. When you click **Submit new issue**, your
answers (name, organization, email, mobile, use case, and the proposed schema) are
captured as a tracked proposal issue our working group reviews.

{% hint style="info" %}
You'll need a free GitHub account to submit. The form opens in a new tab.
{% endhint %}

### 👉 [Propose a new schema](https://github.com/India-Energy-Stack/ies-accelerator/issues/new?template=schema-proposal.yml)

Not sure which use case yours fits? Browse the [Use Cases](use-cases/README.md) section first.
